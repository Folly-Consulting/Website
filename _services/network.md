Most small networks grow by accident: a switch added here, an access point there, and a firewall nobody has touched in years. We start by finding out what is actually in place and how it is used, then recommend changes in a sensible order.

That might be a documented tidy-up, a firewall and switching refresh, a Wi-Fi redesign, or a plan to stage upgrades over time. Where it helps, we do the hands-on work ourselves, and we leave you with up-to-date documentation so the next change is easier than the last.
